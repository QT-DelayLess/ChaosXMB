# 🎮 ChaosXMB

**ChaosXMB**, klasik konsol (Cross Media Bar) arayüz deneyimini Windows masaüstüne taşıyan modern, akıcı ve bağımsız bir oyun kütüphanesi başlatıcısıdır (game launcher).

## ✨ Özellikler

- **Klasik XMB Deneyimi:** Yatay kategoriler ve dikey içerik rayı ile optimize edilmiş, gecikmesiz ve akıcı gezinme[cite: 1].
- **Dinamik Görsel Efektler:** Arka planda gerçek zamanlı render edilen konsol dalga efektleri (wave animation) ve oyunlara özel dinamik arkaplan geçişleri[cite: 1, 2].
- **Oyun ve Mağaza Entegrasyonu:** Steam, Epic Games ve GOG kütüphanelerini otomatik tarama; kapak, tür ve açıklama gibi üst verileri (metadata) otomatik tamamlama[cite: 2].
- **Tam Kontrolcü (Gamepad) & Klavye Desteği:** XInput tabanlı tam kontrolcü uyumluluğu ve klavye kısayolları ile masadan kalkmadan gezinme[cite: 1, 2].
- **İstatistik & Takip:** Toplam oynama süresi, son oynanma tarihi ve oturum istatistiklerini yerel olarak saklama[cite: 1, 2].
- **Hafif & Optimize:** Düşük bellek kullanımı, minimal kaynak tüketimi ve modern WPF mimarisi[cite: 1, 2].

## 🛠️ Teknolojiler
- **C# / .NET**[cite: 2]
- **WPF (Windows Presentation Foundation)**[cite: 1]
- **XInput Controller API**[cite: 2]
- **Steam Store Web API Integration**[cite: 2]
